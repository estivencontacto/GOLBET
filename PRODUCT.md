# Product

## Register

product

## Platform

web

## Users

The primary users are football fans in Colombia who need to review fixtures, results, odds, and match details quickly. A secondary administrative user manages the match catalogue without bypassing the application's layered architecture.

## Product Purpose

GolBet is an academic ASP.NET Core MVC application that demonstrates a complete, understandable N-layer workflow. Success means that a visitor can find relevant matches, combine state filters with a team-name search, inspect a match, and receive clear feedback, while the project remains easy for a student to explain and defend.

## Positioning

GolBet turns the course architecture into a small but coherent football fixture product: every visible result comes through the repository, service, DTO, controller, and view layers.

## Brand Personality

Direct, energetic, and trustworthy. The interface is written in clear Spanish, feels recognizably football-oriented, and avoids casino-like visual pressure.

## Anti-references

Avoid betting-site clutter, fluorescent odds walls, excessive animation, decorative dashboards, and visual complexity that makes the academic architecture harder to understand.

## Design Principles

- Make the current match state and available action obvious.
- Preserve context across filters, search, navigation, and empty states.
- Prefer familiar web controls and plain language over novelty.
- Keep football identity present without overwhelming the task.
- Ensure every UI behavior maps cleanly to code the student can explain.

## Accessibility & Inclusion

Use semantic HTML, keyboard-visible focus, sufficient contrast, descriptive labels, responsive layouts, and reduced-motion behavior. Do not encode match status by color alone.
